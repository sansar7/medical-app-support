# Medical app support

Public privacy policies, support pages, and entirely synthetic review samples for Dental CBCT Studio, Dental 3D, Denthesia, Enamel, Casebook, Easy3D Capture, ToothForm: Dental Anatomy 3D, the Denthesia website, and the local Foundry Call Studio prototype. Dental CBCT Studio, ToothForm and Foundry Call Studio are English only in their current source. Earlier released builds can have different language support. The multilingual products share English, Spanish, French, German, Italian, Brazilian Portuguese, Simplified and Traditional Chinese, Japanese, Korean, Hindi, Arabic, Indonesian, Turkish, and Vietnamese. These public support documents remain in English. No application source, patient data, credentials, or analytics scripts are included.

Hosted by GitHub Pages from main at the repository root. Update the per-app Markdown and run `python3 scripts/render.py` to regenerate HTML together when practices change. To refresh from the app repositories, use `python3 scripts/render.py --source-root /path/to/repositories`. To refresh only selected apps, repeat `--app`, for example `--source-root /path/to/repositories --app cbct --app dentalfacescan --app dentalmorphology --app foundrycallstudio`; other apps keep their bundled documents. The linked CBCT Endo and volume reorientation workflows are published with its support page. Only explicitly selected public documents are copied: support/privacy documents, the two CBCT workflow documents, and ToothForm’s LICENSES.md with an explicit allowlist of 14 model attribution/license .txt notices. ToothForm notice pages retain unchanged plain-text copies and provide readable HTML; historical upstream notices are labeled separately from current sources. Tooth geometry, scan volumes, application source, internal status records and clinic configuration are never published. Links to internal Markdown records are rendered as plain text in the public HTML. `source-sha256.json` records the source document checksums at publication. Enamel uses `DentalEducation/PRIVACY.md` as the canonical source of its bundled `enamel/PRIVACY_POLICY.md` copy.
