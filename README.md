# Medical app support

Public privacy policies, support pages, and entirely synthetic review samples for Dental CBCT Studio, Easy3D, Casebook, and Denthesia. No application source, patient data, credentials, or analytics scripts are included.

Hosted by GitHub Pages from main at the repository root. Update the per-app Markdown and regenerate HTML together when practices change. source-sha256.json records the source document checksums at publication.
