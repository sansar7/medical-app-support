# Medical app support

Public privacy policies, support pages, and entirely synthetic review samples for Dental CBCT Studio, Dental 3D, Casebook, Denthesia, and Enamel. No application source, patient data, credentials, or analytics scripts are included.

Hosted by GitHub Pages from main at the repository root. Update the per-app Markdown and run `python3 scripts/render.py` to regenerate HTML together when practices change. To refresh from the app repositories, use `python3 scripts/render.py --source-root /path/to/repositories`. The source directory is never published. `source-sha256.json` records the source document checksums at publication. Enamel uses `DentalEducation/PRIVACY.md` as the canonical source of its bundled `enamel/PRIVACY_POLICY.md` copy.
